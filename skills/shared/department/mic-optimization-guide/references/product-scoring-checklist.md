# MIC Product Scoring Checklist

## Target Score: 4.6+

Use this checklist to audit and optimize existing MIC products or ensure new products meet quality standards.

---

## Section 1: Basic Information (基本信息)

### Product Name
- [ ] Length: 5-12 words
- [ ] Structure: Modifier + Noun + for + Application + with + Feature
- [ ] Title Case (first letter of each word capitalized)
- [ ] No keyword stuffing
- [ ] No Chinese characters

**Example:** `10.1 Inch Electronic Shelf Label LCD Color Display for Retail with IP65`

### Center Word
- [ ] Matches product name's core noun
- [ ] All keywords' center words match this center word

### Keywords
- [ ] Quantity: 10 slots filled (when product supports)
- [ ] Format: Modifier + Center Word
- [ ] First 3 are most important
- [ ] No duplicates or overly similar terms
- [ ] All center words match product name

### Product Group
- [ ] Correct main category selected
- [ ] Correct sub-category selected (if available)
- [ ] Verified before clicking confirm

### Product Model
- [ ] Filled with actual model number
- [ ] No Chinese characters

---

## Section 2: Product Highlights (产品亮点)

- [ ] Quantity: 10 highlights (fill all when product supports)
- [ ] Each highlight: 1 sentence, 10-20 words
- [ ] Format: Feature Name + Specific capability + Benefit
- [ ] Include keywords naturally
- [ ] Title Case for feature names
- [ ] No empty slots

**Example:** `Custom Size Availability: Offers custom screen sizes to fit specific shelf dimensions and retail layouts`

---

## Section 3: Product Attributes (产品属性)

### Standard Attributes
- [ ] All required fields filled
- [ ] Minimal use of "Other" (select standard option when possible)
- [ ] Custom input filled when "Other" is selected
- [ ] Values accurate per spec sheet
- [ ] Domain knowledge applied when spec silent

### Custom Attributes
- [ ] Quantity: up to 15, fill as many as relevant
- [ ] Attribute names: English only
- [ ] Each value: ≤50 characters
- [ ] Unit Size NOT in custom attributes (goes to 规格管理)
- [ ] Common attributes included: Weight, Case Material, Protection Level, etc.

---

## Section 4: Specification Management (规格管理)

- [ ] At least 1 spec group (MIC recommendation)
- [ ] Unit Size placed here (NOT in custom attributes)
- [ ] Max 60 values per spec
- [ ] Max 5 spec groups
- [ ] Max 300 total combinations

---

## Section 5: FOB Price Settings (FOB价格设置)

- [ ] Pricing mode selected (一口价 / 阶梯价 / 区间价)
- [ ] Prices in USD
- [ ] Competitive with market
- [ ] Clear MOQ
- [ ] Unified 库存 field for ladder price

---

## Section 6: Packaging & Shipping

### Package Dimensions
- [ ] Quantity per carton filled
- [ ] Dimensions (L × W × H in cm)
- [ ] Weight (kg)

### Shipping
- [ ] Shipping template selected
- [ ] Port: Huangpu

### Delivery Efficiency
- [ ] 发货期数量 + 发货期时间 filled
- [ ] Up to 3 rows if applicable

---

## Section 7: Sample Settings (样品单交易设置)

- [ ] Provide samples: Yes
- [ ] Sample price competitive
- [ ] Max sample quantity ≤ MOQ
- [ ] Sample description ≤50 characters
- [ ] Description includes: color, specs, quantity, notes

---

## Section 8: Other Information (其他信息设置)

- [ ] Payment methods selected (L/C, T/T, Paypal)
- [ ] Production capacity filled
- [ ] HS code if available

---

## Section 9: FAQ

- [ ] Quantity: 10 Q&A pairs (fill all when product supports)
- [ ] Questions are real buyer questions
- [ ] Answers are specific (include numbers, specs)
- [ ] No duplicate questions
- [ ] No contradictory answers
- [ ] Grammar correct
- [ ] No Chinese characters

**Grammar checks:**
- [ ] "life time" → "lifetime"
- [ ] "how to shipping" → "how to ship"
- [ ] "Did we receive" → "Will we receive"

---

## Section 10: Product Details (产品详情)

- [ ] Structured with H2/H3 headers
- [ ] Keyword-rich but natural
- [ ] No typos
- [ ] Complete specs table
- [ ] Internal link suggestions included
- [ ] Image alt text suggestions

---

## Section 11: Images (产品展示)

- [ ] Max 6 images uploaded
- [ ] 1 video or GIF (optional)
- [ ] High quality, clear product shots
- [ ] Alt text descriptive

---

## Final Verification

- [ ] All inputs: English only, no Chinese characters
- [ ] No validation errors on preview
- [ ] Score estimate: 4.6+

## Common Score Killers

| Issue | Impact | Quick Fix |
|-------|--------|-----------|
| Empty highlights | -0.5 to -1.0 | Add 10 highlights |
| Empty FAQ | -0.3 to -0.5 | Add 10 Q&A |
| No sample | -0.2 to -0.3 | Enable sample, add description |
| Missing shipping | -0.2 | ~~Select template~~ ARMOR 无运费模板（用户确认 2026-08-13），无需选择 |
| Keyword-stuffed name | -0.3 to -0.5 | Rewrite with proper structure |
| Too many "Other" | -0.1 to -0.2 | Select standard options |
